# Agent Task: Frontend Workflows

## Goal

Build the user-facing screens for daily fleet operations.

## Read first

- `docs/requirements.md`
- `docs/api-design.md`
- `docs/feedback-loops.md`

## Scope

- Dashboard.
- Vehicle pool with filters.
- Vehicle details with history.
- Check-in wizard.
- Loan checkout wizard.
- Loan return wizard.
- Manufacturer check-out wizard.
- Driver management.
- Company management.
- Admin import screen.

## UX requirements

- Mobile-first layout.
- Large touch targets.
- Clear status badges.
- Camera/file upload support.
- Signature capture canvas.
- Clear required fields.
- Field-specific validation errors.
- Role-based actions and navigation.

## Acceptance criteria

- Operations user can complete all MVP workflows from the UI.
- Admin user can access admin screens.
- Loaned vehicles show borrower and expected return.
- Vehicle history shows protocols, photos, signatures, and PDFs.

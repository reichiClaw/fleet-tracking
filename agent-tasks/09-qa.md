# Agent Task: QA and Acceptance

## Goal

Validate that the implemented app is correct, secure enough for internal use,
and deployable.

## Read first

- `docs/requirements.md`
- `docs/backlog.md`
- `docs/deployment.md`

## Test areas

- Login/logout.
- Role-based permissions.
- Vehicle CRUD.
- Excel import.
- Vehicle check-in.
- Vehicle loan checkout.
- Vehicle loan return.
- Manufacturer check-out.
- Damage report creation.
- Photo upload.
- Signature capture.
- PDF generation and download.
- Vehicle status overview.
- Docker Compose startup.
- Data persistence after restart.
- Backup and restore.

## Acceptance criteria

- Critical backend tests pass.
- Critical frontend tests pass.
- Docker Compose can start implemented services.
- No admin-only endpoint is accessible to operations users.
- No mutation endpoint is accessible to read-only users.
- Uploaded files persist.
- Backup and restore instructions are executable.

## Reporting format

For every issue, report:

- Severity.
- File path or endpoint.
- Reproduction steps.
- Expected result.
- Actual result.
- Suggested fix.

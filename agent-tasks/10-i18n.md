# Agent Task: Internationalization

## Goal

Make the application fully usable in German and English.

## Read first

- `docs/i18n.md`
- `docs/requirements.md`
- `docs/api-design.md`

## Scope

- Add frontend i18n infrastructure.
- Add German and English locale resource files.
- Translate navigation, dashboard, vehicle pool, vehicle details, workflow
  wizards, admin/import screens, validation text, empty states, and errors.
- Add a language selector.
- Persist the selected language.
- Use locale-aware date, time, and number formatting.
- Ensure status labels display as translations while stored values remain stable
  codes.
- Add backend translation support for user-facing validation/import messages.
- Ensure PDF protocols can be generated in German and English.

## Acceptance criteria

- A user can switch between German and English.
- The selected language persists after reload.
- The main workflows are fully translated in both languages.
- PDF protocols support German and English labels and titles.
- Generated PDFs store the language code used.
- Translation resources for `de` and `en` contain matching required keys.
- No new user-facing frontend text is hard-coded outside translation resources.

Create the initial React + TypeScript + Vite frontend structure.

## Read first

- `AGENTS.md`
- `docs/architecture.md`
- `docs/api-design.md`
- `docs/i18n.md`

## Scope

- Create React app under `frontend/`.
- Configure TypeScript.
- Add routing.
- Add German and English i18n setup.
- Add API client reading `VITE_API_BASE_URL`.
- Add login page.
- Add authenticated app layout.
- Add dashboard placeholder.
- Add vehicle pool placeholder.
- Add role-aware navigation placeholders.
- Add language selector with persisted preference.
- Add frontend Dockerfile.

## Acceptance criteria

- Frontend starts locally.
- Frontend build succeeds.
- Basic tests or smoke tests exist.
- Documentation is updated with frontend commands.
